# Исправление поля `suppliers` в корзине

## Проблема
- Поле `suppliers` в модели корзины обязательно (`required: true`)
- В контроллере при добавлении товара оно не заполнялось
- Это вызывало ошибку **500** и товары не добавлялись в корзину
- У ранее добавленных товаров отсутствовало значение `suppliers`

## Решение

### 1. ✅ Исправлен контроллер (`src/controllers/cartControllers.js`)
**Добавлено:**
```javascript
suppliers: product.suppliers,
```
при добавлении нового товара в корзину (строка 48).

### 2. 🔧 Заполнение существующих товаров в корзине
Нужно запустить скрипт миграции, который заполнит поле `suppliers` для всех существующих товаров в корзинах:

```bash
npm run migrate:suppliers
```

**Что делает скрипт:**
- Подключается к базе данных
- Находит все корзины с товарами
- Для каждого товара без поля `suppliers` получает его из модели продукта
- Сохраняет обновленные данные в БД
- Выводит статистику обновления

## Результат
После этих изменений:
- ✅ Новые товары будут добавляться в корзину с заполненным полем `suppliers`
- ✅ Существующие товары будут обновлены
- ✅ Ошибок **500** при добавлении товара не будет
